# Family Settings
Owner: SangYoon (B)

`views/FamilySettingsView.vue` imports separate member, invite-code, language, appearance and Telegram panels from `components/`. State/actions live in `composables/`; API calls live in `services/`. The authenticated route is `/settings`; fictional-data preview is `/preview/settings`.

See [Family UI documentation](../../../../docs/FAMILY-UI.md) for supported behavior, backend routes, integration boundaries and validation steps.
